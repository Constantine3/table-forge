# Agent Note：阿瓦隆身份使用校验预设与单一共享规则模块

Status: implemented

[English](2026-08-17-avalon-role-presets.md) | 中文

## 问题

阿瓦隆固定的基础牌组无法表达派西维尔、莫甘娜、莫德雷德与奥伯伦之间的信息关系。允许浏览器任意拼装身份会产生不受支持或不平衡的圆桌；后端与浏览器分别维护目录又会让设置选项、显示数量与实际分配发生漂移。

## 决策

对局配置接受 `rolePreset`，绝不接受任意身份列表。`percival-morgana` 是五人、六人和七人局的默认预设。`basic` 在所有受支持人数中都可用。`mordred-oberon` 仅支持七人局。规则定义会根据 `playerCount` 校验预设、解析完整牌组，并且只有当 `humanRole` 实际出现在解析后牌组中时才接受该值。`avalon/started` 事件会存储预设与完整分配，阿瓦隆规则版本 `11` 会拒绝更早的预发布对局。

纯 `@deepseek-ai/dsh-game-avalon-rules` 包统一维护身份 id、名称、能力说明、阵营关系、协作邪方关系、预设可用性、牌组、任务人数与任务失败门槛。确定性规则定义与阿瓦隆浏览器贡献都会导入其主规则模块，该模块不导入 Cordis、Node、React 或插件运行时。客户端打包纯度门只允许这个精确包，同时继续拒绝更深子路径与游戏插件包根路径。身份分配、动作校验、事件归约与投影仍由规则定义负责。

## 信息投影

私有知识使用带判别字段的条目，不再使用可选的阵营与身份字段。梅林收到除莫德雷德外所有邪方的 `evil` 条目，其中包括奥伯伦。派西维尔收到梅林与莫甘娜的 `merlin-candidate` 条目，但不会收到可供区分的身份。协作邪方收到其他协作邪方的准确 `evil-ally` 条目，其中不含奥伯伦。奥伯伦没有同伴知识。进行中的公开投影会公开所选预设与身份牌组，但绝不公开分配结果。

刺客、莫甘娜、莫德雷德与爪牙组成协作邪方网络。只有该网络参与有序刺杀讨论并看到进行中的发言。奥伯伦可以提交任务失败，但既不参与也看不到讨论。协作邪方任务策略只会列出并协调已知的网络成员；奥伯伦收到不含同伴身份或失败票分工的独立策略。身份专属中文提示覆盖派西维尔尚未分辨的候选、莫甘娜的假梅林行为、莫德雷德造成的梅林盲区、奥伯伦的隔离、刺客对目标的追踪，以及梅林不完整的邪方视野。

## 考虑过的替代方案

**允许自定义拼装身份。** 否决，因为身份数量本身不能证明信息关系受到支持且保持平衡，浏览器也不能成为公平性权威。

**把身份规则留在规则定义中，并向界面复制显示元数据。** 否决，因为预设可用性、名称与牌组数量必须同步变化。

**为每个预设创建一个游戏定义。** 否决，因为各预设共享事件、阶段、任务规则与呈现；经过校验的对局选项属于现有定义。

**允许阿瓦隆游戏插件绕过客户端打包纯度门。** 否决，因为插件根路径会导入 Node 与 Cordis 运行时代码。独立规则包不暴露共享运行时身份。

## 后果

设置只提供公平的完整组合；所选预设不支持新人数时，界面会自动回到默认值。进行中的棋盘会根据投影牌组渲染数量，不再从人数推导。人类身份选择无法请求牌组中不存在的身份。新增预设需要为其信息关系提供一条目录记录，并同步补充投影、提示、界面与快照证据。本决策细化了[事件溯源游戏架构](../architecture/2026-08-14-event-sourced-llm-game-engine.md)中的阿瓦隆实现，但不改变引擎、控制器、隐私或界面贡献分界。
