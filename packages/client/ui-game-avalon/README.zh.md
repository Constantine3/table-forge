# `@deepseek-ai/dsh-client-ui-game-avalon`

[English](README.md) | 中文

该浏览器插件向 `dsh-client-ui-game` 贡献 `avalon` 目录卡片、五席、六席或七席设置和圆桌棋盘。设置默认选择人类参与的六人局与平衡的派西维尔和莫甘娜预设，也允许用户切换到五人局、七人局或全 AI 圆桌，并为每个 AI 席位分别选择提供方。身份设置只允许选择 `@deepseek-ai/dsh-game-avalon-rules` 解析出的预设；莫德雷德与奥伯伦预设仅在七人局出现，切换到不支持的人数时会回到默认预设。设置页和圆桌页都会显示实际身份牌组及数量。每个公开身份数量标签会在鼠标悬停、键盘聚焦或触屏点按聚焦时显示阵营与规则说明，且不会标明任何席位尚未公开的身份。人类参与时可以随机分配，或选择所选牌组实际包含的身份；全 AI 设置会移除该控件，并创建五个、六个或七个 Agent 席位。

游玩期间，全部席位会动态排列在环形牌桌周围，桌心显示选定的发言方向与当前发言者。身份面板会解释人类身份能力，并按知识类型展示私有信息：梅林看到的邪方席位、派西维尔尚未分辨的候选组合，或准确的协作邪方同伴；奥伯伦没有同伴名单。规则投影中的五轮任务人数与结果在桌面宽度下纵排于圆桌旁，在窄屏下恢复为横排；失败门槛超过一票的任务会在执行前标明。顺时针队长轮换提示通过圆桌席位顺序与当前队长样式表达，不会在另一份列表中重复全部席位。存在人类席位时，操作控件来自该席位的当前动作 schema：人类队长先选择初选队伍与方向，每名人类发言者获得发言编辑器，队长的最后一轮会重新启用席位控件，让归票动作保留或调整队伍。全 AI 圆桌只呈现公开观察，不显示动作控件。棋盘分别标明初选队伍和最终队伍，并显示按顺序提交的投票前发言、任务失败票数，以及规则允许的身份信息。每条收起的历史摘要包含匿名赞成票数与否决票数，展开后显示该轮公开发言；所有玩家发言且队长提交最终队伍后才显示投票控件。

三次任务成功后，协作邪方沿顺时针获得私有发言控件，刺客在选择目标前获得最后的总结轮次。他们的投影会显示已提交的私密发言与当前发言者；善方与奥伯伦只显示私下讨论正在进行。刺杀等待状态不会标明行动席位。正常完成会公开全部身份与邪方发言，并允许显式载入 AI 审计；共享审计时间线会把邪方私密发言标为“刺杀前密谈”，把刺客已接受的目标标为“刺杀决策”。放弃对局会继续隐藏尚未公开的身份，并且不提供审计载入。

## 模型体验

### 阿瓦隆呈现

#### 模型看到什么

没有内容。该贡献只渲染 `avalon` 的公开投影或人类席位 Remote 投影，不创建模型请求。

#### Token 影响

零 token。

#### KV Cache 影响

无影响。

## 已知限制与后续工作

- 提供方选择不公开逐席位角色设定编辑。为保证公平性，设置不提供自定义身份拼装，只接受服务端校验的预设。
