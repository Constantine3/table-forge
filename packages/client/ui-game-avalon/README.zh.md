# `@deepseek-ai/dsh-client-ui-game-avalon`

[English](README.md) | 中文

该浏览器插件向 `dsh-client-ui-game` 贡献 `avalon` 目录卡片、固定五席设置和圆桌棋盘。设置允许人类选择身份或保持随机分配，并为四个 AI 席位分别提供独立的提供方选择器。游玩期间，五个席位固定排列在环形牌桌周围，桌心显示选定的发言方向与当前发言者。操作控件来自人类席位的当前动作 schema：人类队长先选择初选队伍与方向，每名人类发言者获得发言编辑器，队长的最后一轮会重新启用席位控件，让归票动作保留或调整队伍。棋盘会分别标明初选队伍和最终队伍，并显示按顺序提交的投票前发言、独占历史记录行的匿名汇总票型、任务失败票数、比分、否决计数，以及规则允许人类知道的身份信息；队长提交第五句发言和最终队伍后才显示投票控件。

三次任务成功后，邪方玩家沿顺时针获得私有发言控件，刺客在选择目标前获得最后的总结轮次。邪方人类投影会显示已提交的邪方发言与当前邪方发言者；非邪方投影只显示私下讨论正在进行。刺杀等待状态不会标明行动席位。正常完成会公开全部身份与邪方发言，并允许显式载入 AI 审计；共享审计时间线会把邪方私密发言标为“刺杀前密谈”，把刺客已接受的目标标为“刺杀决策”。放弃对局会继续隐藏尚未公开的身份，并且不提供审计载入。
