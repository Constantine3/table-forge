# `@deepseek-ai/dsh-client-ui-game-rps`

[English](README.md) | 中文

该浏览器插件向 `dsh-client-ui-game` 贡献 `rps` 目录卡片、设置表单和棋盘。设置支持人类对 AI、AI 对 AI、来自部署 schema 的固定局数，以及为不同席位独立选择可达提供方。创建时会回传 Host 发布的规则版本；若旧 Host 未提供该版本，设置会禁用并提示重启。棋盘呈现封存选择状态、比分、已裁定回合、终局结果、阻塞控制器恢复，以及包含每个模型已接受选择的共享赛后 AI 审计时间线。
