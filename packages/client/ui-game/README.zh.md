# `@deepseek-ai/dsh-client-ui-game`

[English](README.md) | 中文

这个浏览器插件拥有对局配置和游玩的产品根界面。它支持人类对 AI 与 AI 对 AI 的剪刀石头布、固定可配置局数、从已激活配置中选择提供方、封存选择状态、比分历史和对局结果。模型 id、端点、凭据和 AI 角色设定属于部署配置，不作为可编辑的开桌字段。

界面通过生成的 `matches` Remote 命名空间读取已提交对局视图，并在 `match/changed` 后重新获取。它在浏览器存储中记录选中的对局 id，并在导航或刷新后重新加载该服务端持久化视图；选择新对局会先放弃仍活跃的对局并排空其 AI 控制器，再清除浏览器选择。它不会读取 AI Session 对话记录或原始私有对局事件。

## 模型体验

### 对局呈现

#### 模型看到什么

该浏览器插件不增加模型输入。来自 `matches` 视图的 AI 决策在裁定前显示为封存状态，提示词与推理文本不会被渲染。

#### Token 影响

零 token。模型请求由 Agent 控制器拥有。

#### KV Cache 影响

无影响。远程对局刷新不会修改模型历史。

## 已知限制与后续工作

- 一个浏览器只能选择一张当前牌桌；界面尚不列出早期对局，也不展示控制器失败详情。
