# `@deepseek-ai/dsh-client-ui-game`

[English](README.md) | 中文

这个浏览器插件拥有通用游戏产品根界面、持久牌桌列表、游戏目录和共享 Remote 操作。已安装的游戏 UI 插件贡献目录卡片以及按游戏 id 分派的设置与棋盘界面，因此新增游戏不会把游戏专属状态加入根界面。模型 id、端点、凭据和 AI 角色设定属于部署配置，不作为可编辑的开桌字段。

界面通过生成的 `matches` Remote 命名空间读取已提交对局视图，并在 `match/changed` 后重新获取。它在浏览器存储中记录选中的对局 id，并在导航或刷新后重新加载该服务端持久化视图；选择新对局会先放弃仍活跃的对局并排空其 AI 控制器，再清除浏览器选择。恢复、打开、刷新、活跃游玩和放弃都不会读取 AI Session 对话记录或原始私有对局事件。用户只能在正常完成后显式载入完整的 AI Session 历史；已放弃对局不能审计。审计投影会遍历每个 AI 席位的全部历史页，将推理、自然语言输出和提交给游戏工具的参数合并为一条按事件时间排序的时间线，并在每一条中标出玩家、决策阶段、模型回合、时钟时间和工具结果。游戏声明为匿名的决策所对应的全部模型文本和动作字段仍会脱敏，但时间线会标出提交动作的席位。无法读取的席位会明确列出，从而避免把“已载入但没有条目”与“从未请求审计”混为一谈。

浏览器回合通知需要用户选择开启。通用外壳会在用户点击开启控件或创建对局时请求权限；此后，只要页面隐藏或失焦，每个人类可操作窗口最多触发一条通知。可操作窗口即使先在前台出现，在完成前仍保留通知资格，因此让它保持待处理并切走页面仍会收到通知；点击通知会聚焦游戏页。浏览器不支持通知、用户拒绝权限或通知创建失败时，游戏流程不受影响，顶栏会保留相应状态。

## 模型体验

### 对局呈现

#### 模型看到什么

该浏览器插件不增加模型输入。游玩期间，游戏界面只渲染人类安全的 `matches` 投影；AI 推理与提交动作参数只会出现在显式的赛后审计时间线中，但匿名决策回合仍会脱敏。

#### Token 影响

零 token。模型请求由 Agent 控制器拥有。

#### KV Cache 影响

无影响。远程对局刷新不会修改模型历史。

## 已知限制与后续工作

- 一个浏览器同一时间选择一张当前牌桌；目录不提供匹配、观战或多用户身份。
