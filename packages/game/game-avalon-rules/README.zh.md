# `@deepseek-ai/dsh-game-avalon-rules`

[English](README.md) | 中文

`dsh-game-avalon-rules` 是阿瓦隆规则定义与浏览器设置共享的纯规则目录。它统一维护五人、六人和七人局支持的身份 id、中文名称与能力说明、阵营与协作邪方关系、公平预设牌组、任务人数和任务失败门槛。

公开 API 只解析完整预设：`basic` 与 `percival-morgana` 支持所有人数，`mordred-oberon` 仅支持七人局。该包不分配席位、不校验动作、不归约事件，也不投影私有信息；这些职责仍属于 `dsh-game-avalon`。

## 模型体验

### 阿瓦隆身份与任务目录

#### 模型看到什么

该包不会发起模型请求。`dsh-game-avalon` 会把解析后的牌组、任务规则、身份名称和能力说明写入各席位的中文私有提示词。

#### Token 影响

该包自身不增加提示词；消费者决定需要包含哪些解析后的规则事实。

#### KV Cache 影响

一个对局的预设元数据保持不变，因此消费者渲染的规则文本可以位于稳定的提示词前缀。

## 已知限制与后续工作

- 该目录有意只支持经过校验的五人、六人和七人预设；任意身份列表和八人以上任务表不属于该包。
