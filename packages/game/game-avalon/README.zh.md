# `@deepseek-ai/dsh-game-avalon`

[English](README.md) | 中文

`dsh-game-avalon` 注册五人和六人阿瓦隆规则定义，席位可由一名人类与其余 AI 组成，也可全部由 AI 控制。设置会选择圆桌人数，并可把唯一的人类固定为梅林、刺客、亚瑟的忠臣或莫德雷德的爪牙；全 AI 圆桌和未指定人类身份的对局使用私有随机种子分配所有身份。五人局有两名忠臣，六人局有三名。完整分配结果与初始队长会写入持久规则事件，因此回放保持确定性。

五人局的五次任务人数依次为 2、3、2、3、3，六人局则为 2、3、4、3、4。队长公开初选队伍并选择顺时针或逆时针讨论；指定方向上的相邻席位先发言，所有非队长依次发言，队长在最后的归票发言动作中提交将要投票的最终队伍。队长可以保留初选队伍，也可以根据讨论更换成员。五人或六人的全部发言提交后，每个席位才收到不附带陈述的封存赞成票或否决票。队伍必须获得严格多数票：五人局至少三票，六人局至少四票。结算只记录并公开赞成票数与否决票数，绝不公开具名席位的选择。最终队伍通过后，其中的队员提交封存任务动作。善方角色只能提交成功，邪方角色可以提交成功或失败。队伍被否决会增加连续否决计数，任一队伍通过会把该计数清零；三次任务失败或连续五支队伍被否决时邪方立即获胜。三次任务成功后，邪方从刺客之后的席位开始沿顺时针私下轮流发言，刺客最后总结；全部邪方发言完成后，刺客才收到私有目标动作。正常裁定后会公开全部身份与邪方讨论。

进行中的公开视图不含身份。席位投影只包含该席位的身份与规则允许的知识：梅林看到两个邪方席位，邪方玩家互相识别，忠臣没有额外身份信息。刺杀前私密讨论期间，只有邪方席位投影包含当前发言者和已经提交的发言；非邪方投影不会收到两者。队伍投票历史只公开汇总的赞成与否决票数；任务历史只公开失败票数，不公开个人动作。

## 对局设置

- `playerCount` 选择 `5` 或 `6` 个席位，API 调用方省略时默认为 `5`；浏览器设置默认选择六人局。
- 席位必须全部由 AI 控制，或者恰好包含一名人类且其余席位全部由 AI 控制。
- `humanRole` 可以把唯一的人类席位固定为 `merlin`、`loyal-servant`、`assassin` 或 `minion`；全 AI 圆桌不能使用该字段，省略时保持随机分配。

## 配置

- `maxStatementChars` 限制每条投票前公开发言或邪方私密发言，默认为 `280`。

## 模型体验

### 阿瓦隆动作

#### 模型看到什么

AI 收到所选圆桌的身份牌组、任务人数、严格多数门槛、当前席位投影，以及只描述其当前合法动作（例如 `propose-team`、`make-statement`、`make-evil-statement` 或 `quest`）的 JSON schema。规则提示明确说明队伍投票匿名且只公开汇总票数、只有连续否决才会让邪方获胜，并且任一队伍通过都会清零计数。队长最后的 `make-statement` schema 同时要求归票发言和最终队伍，其他发言者只提交发言。提示词要求其思维链、自然语言输出与发言全部使用简体中文；公开发言不得披露或转述私有身份知识，邪方私密讨论则可以使用这些知识。不含中文文本的 AI 发言会被拒绝。

#### Token 影响

每次 AI 提案、投票前发言、队伍投票、任务动作、邪方讨论发言或刺杀选择都会增加一段规则与观察提示词。每次提案之后，每个席位会依次获得一个发言动作。一名人类参与时，五人局会触发四个 AI 发言回合，六人局会触发五个；全 AI 圆桌则会触发五个或六个。终局会增加两个串行邪方发言动作；全 AI 圆桌的两个动作都会触发 AI 回合，混合圆桌则根据人类身份触发其中一个或两个。

#### KV Cache 影响

规则前缀对同一席位保持稳定；任务历史、公开陈述、私有观察与动作 schema 会随事件提交而变化。

## 已知限制与后续工作

- 该插件刻意不提供更多阿瓦隆身份、七人及以上圆桌、自由聊天、观战策略或社交内容治理。
