# `@deepseek-ai/dsh-game-avalon`

[English](README.md) | 中文

`dsh-game-avalon` 注册五人、六人和七人阿瓦隆规则定义，席位可由一名人类与其余 AI 组成，也可全部由 AI 控制。设置只能选择经过校验的身份预设，不能任意拼装身份。所有支持人数默认使用 `percival-morgana`：五人局由梅林、派西维尔、一名亚瑟的忠臣、刺客与莫甘娜组成；六人局增加一名忠臣；七人局再增加一名忠臣和一名爪牙。`basic` 使用梅林、刺客、两名或三名忠臣与一名或两名爪牙。七人局还可选择 `mordred-oberon`，由梅林、三名忠臣、刺客、莫德雷德与奥伯伦组成。完整分配结果、预设与初始队长会写入持久规则事件，因此回放保持确定性。

五人局的五次任务人数依次为 2、3、2、3、3，六人局为 2、3、4、3、4，七人局为 2、3、3、4、4。队长公开初选队伍并选择顺时针或逆时针讨论；指定方向上的相邻席位先发言，所有非队长依次发言，队长在最后的归票发言动作中提交将要投票的最终队伍。队长可以保留初选队伍，也可以根据讨论更换成员。所有席位完成发言后，每个席位才收到不附带陈述的封存赞成票或否决票。队伍必须获得严格多数票：五人局至少三票，六人局和七人局至少四票。结算只记录并公开赞成票数与否决票数，绝不公开具名席位的选择。最终队伍通过后，其中的队员提交封存任务动作。善方角色只能提交成功，邪方角色可以提交成功或失败。除七人局第四次任务需要两张失败票外，其他任务有一张失败票就会失败；浏览器和模型投影会公开全部五轮门槛。队伍被否决会增加连续否决计数，任一队伍通过会把该计数清零；三次任务失败或连续五支队伍被否决时邪方立即获胜。三次任务成功后，协作邪方从刺客之后的席位开始沿顺时针私下轮流发言，刺客最后总结；奥伯伦既不参与也看不到讨论。协作邪方发言完成后，刺客才收到私有目标动作。正常裁定后会公开全部身份与邪方讨论。

进行中的公开视图不含身份分配，但会公开所选预设与身份数量。席位投影只包含该席位的身份与规则允许的知识。梅林看到除莫德雷德外的邪方，包括奥伯伦。派西维尔会收到两个无法分辨的梅林候选：梅林与莫甘娜。刺客、莫甘娜、莫德雷德和爪牙会准确识别其他协作邪方，但看不到奥伯伦；奥伯伦看不到任何邪方同伴。刺杀前私密讨论期间，只有协作邪方投影包含当前发言者和已经提交的发言。队伍投票历史只公开汇总的赞成与否决票数；任务历史只公开失败票数，不公开个人动作。

浏览器安全的 `@deepseek-ai/dsh-game-avalon-rules` 包统一维护身份 id、名称、能力说明、阵营关系、合法预设牌组和任务规则。确定性规则定义与浏览器设置共同使用这个纯包；身份分配、动作合法性、持久事件和私有投影仍由服务端负责。

## 对局设置

- `playerCount` 选择 `5`、`6` 或 `7` 个席位，API 调用方省略时默认为 `5`；浏览器设置默认选择六人局。
- `rolePreset` 选择 `basic`、`percival-morgana`，或者仅七人局可用的 `mordred-oberon`；默认值为 `percival-morgana`。
- 席位必须全部由 AI 控制，或者恰好包含一名人类且其余席位全部由 AI 控制。
- `humanRole` 可以把唯一的人类席位固定为解析后预设中实际包含的身份；全 AI 圆桌不能使用该字段，省略时保持随机分配。

## 配置

- `maxStatementChars` 限制每条投票前公开发言或邪方私密发言，默认为 `280`。

## 模型体验

### 阿瓦隆动作

#### 模型看到什么

AI 收到所选圆桌的准确预设牌组、任务人数、任务失败门槛、严格多数门槛、当前席位投影，以及只描述其当前合法动作（例如 `propose-team`、`make-statement`、`make-evil-statement` 或 `quest`）的 JSON schema。规则提示明确说明队伍投票匿名且只公开汇总票数、只有连续否决才会让邪方获胜，并且任一队伍通过都会清零计数。提示会区分发言与证据，禁止把汇总票型归因给其他具名席位，说明任务成功不能证明全体队员属于善方，并要求把任务失败视为邪方进度而非无代价试探。身份策略要求派西维尔比较并保护候选而不暴露范围，莫甘娜模仿掌握隐藏知识的判断，莫德雷德利用梅林的视野盲区，刺客持续追踪梅林，并提醒梅林未被看见的莫德雷德不能因此视为善方。协作邪方任务策略只会列出协作同伴，并提供一条确定的顺时针约定以提交所需失败票。奥伯伦收到独立任务策略，不会得到同伴名单、失败票分工或私密讨论。队长最后的 `make-statement` schema 同时要求归票发言和最终队伍，其他发言者只提交发言。提示词要求其思维链、自然语言输出与发言全部使用简体中文；公开发言不得披露或转述私有身份知识，协作邪方私密讨论则可以使用这些知识。不含中文文本的 AI 发言会被拒绝。

#### Token 影响

每次 AI 提案、投票前发言、队伍投票、任务动作、邪方讨论发言或刺杀选择都会增加一段规则与观察提示词。每次提案之后，每个席位会依次获得一个发言动作。一名人类参与时，五人、六人或七人局分别会触发四个、五个或六个 AI 发言回合；全 AI 圆桌则会触发五个、六个或七个。终局会按所选牌组增加两个或三个串行协作邪方发言动作；七人 `mordred-oberon` 预设仍只有两个，因为奥伯伦不参与。

#### KV Cache 影响

规则与阵营前缀对同一席位保持稳定；阶段策略、任务历史、公开陈述、私有观察与动作 schema 会随事件提交而变化。
