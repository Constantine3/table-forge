# `@deepseek-ai/dsh-game-persistence-sqlite`

[English](README.md) | 中文

该提供方在 SQLite 中存储对局头与只追加事件。创建对局会在一个事务中提交头记录和初始事件；之后的每次追加检查预期修订号，并在一个事务中提交完整事件批次。加载的头记录、席位、事件信封和 JSON 值在进入引擎前都会经过验证。带未知 schema 或对局格式的数据库会被拒绝；预发布格式不迁移。

使用专用数据库路径配置 `path`。测试支持 `:memory:`。

## 模型体验

### 持久对局日志

#### 模型看到什么

没有直接内容。控制器收到引擎重建的投影，而非 `match_events` 行。

#### Token 影响

零 token。

#### KV Cache 影响

无影响；持久化不会修改模型请求或 Session 历史。

## 已知限制与后续工作

- 预发布 schema 或对局格式变化需要新数据库；尚未实现迁移与归档导出。
