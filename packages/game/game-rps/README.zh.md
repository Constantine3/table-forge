# `@deepseek-ai/dsh-game-rps`

[English](README.md) | 中文

`dsh-game-rps` 注册 `rps` 游戏定义。一场对局恰有两个席位与固定正整数 `roundCount`；`maxRounds` 限制部署成本，默认为 20。

每局开启一个公开同时动作窗口，并向两名玩家提供相同的席位专属选择 schema。选择保留在提交事件中，直到两个席位都行动；随后 `rps/round-resolved` 公开双方选择并记录胜者。对局恰好在配置局数后结束，同分为平局。

## 配置

- `defaultRounds` 默认为 `3`。
- `maxRounds` 默认为 `20`，且不得小于 `defaultRounds`。

## 模型体验

### 剪刀石头布动作

#### 模型看到什么

AI 看到剪刀石头布规则、当前席位观察，以及只接受 `rock`、`paper` 或 `scissors` 的 schema。提示词要求思维链与自然语言输出使用简体中文，同时保持这些协议枚举值不变。封存的对手选择不存在于输入中。

#### Token 影响

每个 AI 动作请求增加一段紧凑的规则与状态提示词。

#### KV Cache 影响

规则前缀稳定；回合历史与动作窗口标识追加变化内容。

## 已知限制与后续工作

- 该定义只支持两个席位和固定局数；锦标赛对阵与其他计分方式不属于本插件。
