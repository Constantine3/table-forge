# `@deepseek-ai/dsh-game`

[English](README.md) | 中文

`dsh-game` 定义带版本的确定性游戏，以及控制器与产品客户端使用的持久对局操作。游戏插件发布经部署配置解析后的配置 schema，验证 JSON 配置和席位专属动作、产生规则事件、将事件归约为状态、声明一个待处理动作窗口，并投影公开或席位范围的视图。Remote 游戏目录会把该 schema 与当前规则版本一起返回；设置客户端在创建请求中回传所见版本，使过期客户端无法按已变化的规则创建对局。目录缺少版本表示 Host 尚未实现该握手，客户端必须禁用创建。动作窗口还声明参与席位 id 与提交状态是公开可见，还是只对必需行动的席位可见。

对局日志与 AI 玩家 Session 日志具有不同所有权。对局事件是权威游戏结果；Session 事件只重建该玩家看到并发送给模型的内容。定义不得执行 I/O、调用模型或修改归约器输入。

注册是 effect。注册表监听器会先收到当前已有条目，再收到后续注册，因此消费者可以不依赖插件激活顺序地恢复持久化工作。重复定义 id 与未知规则版本会失败，不会选择隐式回退。

## 模型体验

### 规则定义

#### 模型看到什么

定义使用 `modelPrompt` 渲染 AI 控制器消费的规则与精确席位范围观察。每个当前席位还提供其当下动作使用的 JSON schema，从而支持按角色变化的选择，而不暴露其他席位的合法动作。该服务自身不发送请求。

#### Token 影响

渲染的提示词在每次控制器请求中贡献 token；大小取决于游戏视图。

#### KV Cache 影响

稳定规则可形成可复用前缀，而当前观察会随已提交事件变化。

## 已知限制与后续工作

- 服务定义不提供匹配、观战、计时或玩家身份；产品插件必须独立增加这些能力。
